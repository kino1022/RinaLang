# 宣言
```
class class_name {
    //コンストラクタ
    class_name() {
    }
    //デストラクタ
    ~class_name() {
    }
}
```
# 説明

- メンバと関数を持つことのできる基本的な型宣言です。
- コンストラクタとデストラクタはオプションで、必要に応じて定義できます。


- new演算子を使用してインスタンスを生成した場合に渡される値はそのインスタンスの実態になります。
  - つまりrinalangにおいてはclassは値型であると言えます。


- classは値型であるが、操作をする際にコピーする必要を省くためにmutキーワードを利用した場合にのみフィールドを操作することができます。
